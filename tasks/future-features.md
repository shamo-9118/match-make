## 3. CSVエクスポート + セッション履歴の組み合わせ

### 方針
- 直近10〜20セッションを localStorage に保持 → アプリ内で履歴閲覧可能
- セッション終了時に CSV 自動ダウンロード → Files アプリに蓄積（永続記録）
- 上限を超えた古いセッションは localStorage から自動削除（CSV が残る）

### 注意事項
- iPad（Safari/PWA）ではディレクトリ自動作成は不可（File System Access API 非対応）
- CSV は Files アプリの「ダウンロード」フォルダに保存される
- ファイル名に日付を付与して管理しやすくする（例: `match-make_2026-06-21.csv`）
- アプリから Files アプリの CSV を自動読み込みはできない（ユーザーの手動選択が必要なため UX が悪い）

工数: 中
